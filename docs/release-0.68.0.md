# Kilo Proxy 0.68.0

BYOK visibility in the model catalog and library.

- Shows a BYOK badge when the authenticated Kilo catalog reports an enabled BYOK connection for a model in the selected account or team.
- Adds a dedicated Models with BYOK section to the catalog while preserving all other available models and the existing selection controls.
- Refreshes badges from the current catalog when switching accounts or teams, keeping native ChatGPT models separate.

The label describes availability. It does not identify the underlying credential or assert commercial agreements, discounts or the billing of an individual request.
